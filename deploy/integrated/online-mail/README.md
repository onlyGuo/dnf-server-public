# 游戏在线邮件通知组件

平台保存邮件后写入通知队列；运行中的游戏频道通过本地目录领取请求，在游戏主循环中调用游戏自身的新邮件通知。它只发送通知，邮件和附件仍使用原有数据库保存方式。

- `mail_notify.c` 是组件源码，`mail_notify.so` 是随集成服务使用的 32 位 Linux 组件。
- `prepare.py` 在不覆盖自定义启动脚本的前提下准备组件，并备份原脚本。一体化服务启动时，启用的频道会自动加载组件，无需指定频道；同一大区至少有一个正常运行的频道加载组件即可处理通知。
- `supported-sha256.txt` 限定已核对的游戏程序。其他版本不会加载组件，平台会提示在线提醒未确认。

组件需与已有 `/dp2/libhook.so` 同时加载。重新编译时使用兼容游戏运行库的 32 位 Linux 工具链，并保留帧指针，例如：

```bash
gcc -m32 -O2 -fPIC -fno-omit-frame-pointer -shared \
  -o mail_notify.so mail_notify.c -ldl -lpthread
```

调整支持的游戏版本前，需重新核对游戏邮件接口、主循环调用位置和数据结构，并在隔离环境验证；不能只添加文件摘要。
